# Gold Rush

A co-op gold mining game for Windows: stake a claim, dig, wash and pan for gold, and build up to wash plants and heavy machines with your friends.

## Install

1. Open **[Releases](https://github.com/Slinky1on1/Gold-fields/releases/latest)** and download `GoldRush-<version>-Windows.zip`.
2. Unzip the whole folder somewhere of your own (for example *Documents*), keeping `GoldRush.exe` and `GoldRush.pck` together.
3. Double-click `GoldRush.exe`. If Windows says *"Windows protected your PC"*, click **More info**, then **Run anyway** (the game is not signed).

## Updates

From version 0.14.1 on, the game updates itself: when you open it, it checks this page, downloads the new version and restarts. Keep the game in a folder you can write to (not *Program Files*).

Playing together needs everyone on the same version; the lobby tells you if someone's copy is different.

This repository only holds the game's downloads.
